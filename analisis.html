Sobre este Análisis

Este pipeline de Machine Learning analiza la popularidad de canciones en Spotify utilizando características musicales como danceability, energy, valence, acousticness, y más.

Modelos Entrenados:

  • Linear Regression: Modelo base de regresión lineal
  • Ridge Regression: Regresión con regularización L2
  • Random Forest: Ensemble de árboles de decisión
  • Gradient Boosting: Boosting de gradiente para mejor precisión

Features Utilizados:

is_explicit danceability energy valence acousticness instrumentalness liveness speechiness loudness tempo
